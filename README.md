## 🌦️ WeatherApp

WeatherApp é um aplicativo desenvolvido em Flutter que fornece informações climáticas em tempo real. Com ele, você pode verificar a temperatura, umidade e previsão do tempo.

## 📌 Funcionalidades

- Exibição da temperatura atual

- Informação sobre a umidade do ar

- Previsão do tempo indicando se vai chover

- Interface intuitiva e responsiva

## 🛠️ Tecnologias Utilizadas

- Flutter: Framework principal para desenvolvimento do app

- Dart: Linguagem de programação utilizada

- API de Geolocalização: Utilizamos o Geocode para obter a latitude e longitude do local desejado

- API de Clima: Utilizamos o WeatherAPI  para buscar as condições climáticas exatas com base nas coordenadas
