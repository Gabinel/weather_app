## 🌦️ WeatherApp

WeatherApp é uma aplicação desenvolvida em Flutter que fornece informações climáticas em tempo real. Com ele, você pode verificar a temperatura, umidade e previsão do tempo, incluindo alertas sobre possíveis chuvas.

<br>

## 🛠️ Tecnologias Utilizadas

- Flutter: Framework principal para desenvolvimento do app

- Dart: Linguagem de programação utilizada

- API de Clima: Para obter dados meteorológicos em tempo real
